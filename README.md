# ScreenBeat.js - Concert Screen Strobe

ScreenBeat.js turns your smartphone screen into a concert-style light show that flashes bright white in sync with real-time music beats detected through your microphone.

[Live Demo](https://dicoba-yuks.github.io/screenbeat-app/)

## Features

* **Real-time Beat Detection:** Listens to ambient music and drum beats via microphone.
* **Edge UI Layout:** Controls are pinned to the top and bottom edges, keeping the center screen completely clear for maximum light output.
* **High-Contrast Text:** UI elements utilize CSS `mix-blend-mode` to ensure clear visibility against flashing backgrounds.
* **Dual Sensitivity Control:** Synchronized slider and numeric input field (0 - 255) for exact volume threshold adjustment.

## Technologies Used

* HTML5
* CSS3 (Flexbox, Fixed Positioning, CSS Transitions)
* JavaScript (ES6+)
* **Web Audio API:** For real-time frequency analysis.

## How to Use

1. Open the [Live Demo Link](https://dicoba-yuks.github.io/screenbeat-app/) on your mobile phone.
2. Tap **"Start Flashing"** at the top right.
3. Allow microphone access when prompted.
4. Play ambient music and adjust the **Sound Sensitivity** control at the bottom edge for optimal screen strobe flashes.
